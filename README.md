# Organizador de Imposto de Renda — Excel

# Sobre o projeto
Planilha desenvolvida no Microsoft Excel para organizar informações financeiras e documentos necessários para a declaração do Imposto de Renda.

# Funcionalidades
Registro de rendimentos bancários.
Controle de saldos por instituição financeira.
Organização de informes de rendimentos e anexos.
Consolidação automática dos valores.

# Ferramentas utilizadas
Microsoft Excel
Fórmulas e funções
Gráficos e formatação de células
Objetivo
Facilitar a organização e a conferência de informações financeiras, centralizando dados e documentos em uma única planilha.
